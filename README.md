# 📊 AMS PRO - Student Attendance Management System

A comprehensive web-based attendance tracking platform designed to streamline student records, daily attendance monitoring, and administrative reports.

## 🛠️ Tech Stack & Tools
* **Backend:** PHP & MySQL (Database Management)
* **Frontend:** HTML5, CSS3, & JavaScript (Interactive UI)
* **Design Pattern:** Modern Dashboard Layout with Responsive Components

## 🚀 Key Features
* **Real-time Dashboard:** Quick overview of today's attendance, late arrivals, and total registered students.
* **Attendance Tracking:** Seamless logging and monitoring of student attendance records.
* **System Settings & Controls:** Interactive features including theme toggling, data export, and system configuration.
* **Secure Database Integration:** Reliable data storage and retrieval using MySQL.
